Dictionary of Spoken Spanish

Each word is a tool. Each definition is a rule for how reality is described. Each pronunciation is how sound becomes sense.

It contains the core of the language:
  • Nouns for things
  • Verbs for actions
  • Adjectives for qualities
  • Adverbs for precision
It shows how words change with:
  • Masculine / Feminine
  • Singular / Plural
Agreement is law, not suggestion.

It shows verb conjugations:
  • Tense = time control
  • Person = responsibility
  • Mood = intention
  • Indicative: what is
  • Subjunctive: what might be
  • Imperative: what must be done
It records origins:
  • Latin roots
  • Arabic influence
  • History frozen inside syllables
