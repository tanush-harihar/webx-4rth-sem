Projects

Flow 2 Code

Flow 2 Code is a desktop application that lets users visually construct flowcharts and automatically translate them into working code. It parses logical nodes such as conditions, loops, and process blocks, generating structured output across multiple languages including Java, Python, JavaScript, and C++, bridging the gap between visual algorithm design and real-world programming for beginners.

Budget Manager

Budget Manager is a personal finance application that helps users track income, expenses, and spending habits by categorizing transactions into groups such as essentials, entertainment, and savings, providing meaningful insights into financial behavior through a simple and intuitive interface.

Racing Game

An interactive racing game built around responsive vehicle physics, collision detection, and smooth performance optimization, offering practical experience in game loop design, real-time debugging, and iterative gameplay refinement to deliver an engaging driving experience.

Ohmdex

Ohmdex is an Android AR application built in Unreal Engine 5 that makes electronics education interactive and engaging. Users can scan real-world components using ARCore to instantly retrieve component data, collect and catalog parts through a collectables system, and receive intelligent circuit suggestions through a built-in recommendation model — think SuperCook, but for electronics.

Portfolio Manager

Portfolio Manager is an Android application designed to help users track and manage their investment portfolio on the go. The app allows users to monitor holdings, visualize performance through charts, and stay on top of their financial assets, combining clean mobile UI design with practical data visualization using MPAndroidChart.
